# Linux Security Monitoring & Incident Detection Lab

## Overview

A hands-on cybersecurity homelab designed to develop
practical Linux administration, system hardening,
security monitoring and incident investigation skills.

## Objectives

- Develop Linux administration skills
- Harden a Linux server
- Configure SSH securely
- Implement firewall controls
- Deploy security monitoring
- Detect suspicious activity
- Investigate security incidents
- Develop security automation scripts
